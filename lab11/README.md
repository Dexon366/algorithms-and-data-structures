## Теоретическая часть
**Граф** — совокупность вершин и рёбер. **Матрица смежности** — квадратная матрица V×V, где элемент `[i][j]` равен весу ребра (или 1 для невзвешенного). **Список смежности** — массив списков соседей.

**DFS (поиск в глубину)** — идём вглубь, пока возможно, затем возвращаемся. Реализуется рекурсивно или через стек. **BFS (поиск в ширину)** — посещаем все соседние вершины, затем их соседей (по уровням). Реализуется через очередь.

## Описание реализованного алгоритма

### Матрица смежности
Класс `Graph` хранит `vector<vector<int>> adjMatrix`. `0` означает отсутствие ребра, положительное число — вес. Для неориентированного графа матрица симметрична.

### DFS (рекурсивный)
Функция `dfsUtil` помечает вершину посещенной, выводит её и рекурсивно вызывает себя для всех непосещенных смежных вершин.

### BFS
Используется очередь. Начинаем с `start`, помечаем посещенной, добавляем в очередь. Пока очередь не пуста, извлекаем вершину, выводим, добавляем всех непосещенных соседей.

### Проверка цикла
Для неориентированного графа: при обходе DFS, если встречаем посещенную вершину, которая не является родителем текущей, значит есть цикл.

### Компоненты связности
Запускаем BFS из каждой непосещенной вершины, собирая все достижимые вершины в компоненту.

### Кратчайший путь (BFS)
Используем BFS для нахождения кратчайшего пути по количеству рёбер (не по весу). Восстанавливаем путь через массив `prev`.

## Описание основных функций и структур данных
*   **`Graph`** — класс графа на матрице смежности.
*   **`addEdge`, `removeEdge`** — добавление/удаление рёбер.
*   **`DFS`, `BFS`** — обходы.
*   **`hasCycle`** — проверка цикла.
*   **`printConnectedComponents`** — компоненты связности.

## Анализ сложности
| Операция | Матрица смежности |
| :--- | :--- |
| Добавление ребра | O(1) |
| Удаление ребра | O(1) |
| Проверка наличия ребра | O(1) |
| Перебор всех соседей | O(V) |
| DFS / BFS | O(V^2) |
| Память | O(V^2) |

## Ответы на контрольные вопросы
<details>
<summary>1. Что такое граф? Из каких элементов он состоит?</summary>
Граф — совокупность вершин и рёбер, соединяющих пары вершин.
</details>

<details>
<summary>2. Чем отличается ориентированный граф от неориентированного?</summary>
В ориентированном рёбра имеют направление (дуги), в неориентированном — нет.
</details>

<details>
<summary>3. Что такое матрица смежности? Каковы её достоинства и недостатки?</summary>
Квадратная матрица V×V. Достоинства: быстрая проверка наличия ребра O(1). Недостатки: память O(V^2), медленный перебор соседей O(V).
</details>

<details>
<summary>4. Что такое список смежности? Каковы его достоинства и недостатки?</summary>
Массив списков соседей. Достоинства: память O(V+E), быстрый перебор соседей. Недостатки: проверка наличия ребра O(deg(v)).
</details>

<details>
<summary>5. В каких случаях лучше использовать матрицу смежности, а в каких - список смежности?</summary>
Матрица — для плотных графов (E ≈ V^2). Список — для разреженных (E << V^2).
</details>

<details>
<summary>6. Какова сложность проверки наличия ребра в матрице смежности? В списке смежности?</summary>
Матрица: O(1). Список: O(deg(u)).
</details>

<details>
<summary>7. Какова сложность перебора всех соседей вершины в матрице смежности? В списке смежности?</summary>
Матрица: O(V). Список: O(deg(u)).
</details>

<details>
<summary>8. Что такое поиск в глубину (DFS)? Как он работает?</summary>
Алгоритм обхода, идущий вглубь до тупика, затем возвращающийся. Реализуется рекурсивно или через стек.
</details>

<details>
<summary>9. Какие задачи решаются с помощью DFS?</summary>
Поиск компонент связности, проверка циклов, топологическая сортировка, поиск мостов.
</details>

<details>
<summary>10. Что такое поиск в ширину (BFS)? Как он работает?</summary>
Алгоритм обхода по уровням. Использует очередь. Сначала посещает всех соседей, затем их соседей.
</details>

<details>
<summary>11. Какие задачи решаются с помощью BFS?</summary>
Поиск кратчайшего пути в невзвешенном графе, проверка двудольности, поиск компонент связности.
</details>

<details>
<summary>12. В чём отличие рекурсивной реализации DFS от итеративной?</summary>
Рекурсивная использует стек вызовов, итеративная — явный стек. Итеративная может быть эффективнее по памяти.
</details>

<details>
<summary>13. Почему BFS находит кратчайший путь в невзвешенном графе, а DFS - нет?</summary>
BFS исследует вершины в порядке возрастания расстояния от старта. DFS может уйти в длинный путь, не являющийся кратчайшим.
</details>

<details>
<summary>14. Как найти компоненты связности графа с помощью DFS?</summary>
Запускаем DFS из каждой непосещенной вершины. Каждый запуск формирует одну компоненту.
</details>

<details>
<summary>15. Как проверить наличие цикла в графе с помощью DFS?</summary>
Для неориентированного: если при обходе встречаем посещенную вершину, не являющуюся родителем. Для ориентированного: если встречаем вершину в текущем стеке рекурсии.
</details>
