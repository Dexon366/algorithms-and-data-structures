## 📝 Постановка задачи

### Вариант 6. Продвинутый уровень

Разработать **шаблонный контейнер `PriorityQueue<T>`** на основе **бинарной кучи (max-heap)**.

**Требуемые операции:**
- `push(x)` — добавить элемент;
- `pop()` — извлечь максимальный;
- `top()` — посмотреть максимальный;
- `isEmpty()` — проверка на пустоту;
- `size()` — количество элементов.

**Дополнительно:**
- Указать сложность каждой операции.
- Провести **сравнение с `std::priority_queue`** из STL (таблица, замеры времени).
- Приложить ссылку на Git-репозиторий.
