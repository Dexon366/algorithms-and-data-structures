## Теоретическая часть
Связный список — это структура данных, состоящая из узлов, каждый из которых содержит данные и указатель(и) на соседние узлы. В отличие от массива, элементы списка не хранятся в памяти непрерывно.

**Односвязный список** хранит только указатель на следующий узел. Это экономит память, но позволяет двигаться только в одном направлении.
**Двусвязный список** хранит указатели на следующий и предыдущий узлы, что позволяет обходить список в обоих направлениях, но требует больше памяти.

**Итераторы** — это объекты, позволяющие перебирать элементы контейнера. В списках итераторы обычно реализуются как указатели на узлы с перегруженными операторами `*`, `++`, `!=`.

## Описание реализованного алгоритма

### Управление памятью
Оба класса используют динамическое выделение памяти для узлов. Деструкторы вызывают метод `clear()`, который последовательно удаляет все узлы, предотвращая утечки памяти.

### Односвязный список
*   **`push_front` / `push_back`**: добавление в начало и конец за O(1) благодаря хранению указателя `tail`.
*   **`pop_front`**: удаление из начала за O(1).
*   **`printEverySecond`**: проходит по списку, используя флаг для вывода каждого второго элемента.

### Двусвязный список
*   **`rotateLeft(int k)`**: находит новый хвост (элемент с индексом `k % size - 1`), разрывает связь, и переставляет части списка. Сложность O(n) из-за поиска узла.
*   **`saveToFile` / `loadFromFile`**: используют `ofstream` и `ifstream` для записи/чтения количества элементов и самих данных. Это позволяет сохранять состояние списка между запусками.

### Итераторы
Реализованы вложенные классы `Iterator` для обоих списков. Они инкапсулируют указатель на узел и предоставляют операции `*`, `++`, `==`, `!=`. Это позволяет использовать range-based for.

## Описание основных функций и структур данных
*   **`SinglyLinkedList<T>`** — класс односвязного списка.
*   **`DoublyLinkedList<T>`** — класс двусвязного списка.
*   **`push_back` / `push_front`** — добавление элемента. O(1).
*   **`pop_back` / `pop_front`** — удаление элемента. O(1) для двусвязного (с хвоста), O(n) для односвязного (с хвоста).
*   **`rotateLeft`** — сдвиг списка. O(n).
*   **`saveToFile` / `loadFromFile`** — сериализация. O(n).

## Ответы на контрольные вопросы
<details>
<summary>1. Чем связный список отличается от динамического массива?</summary>
Связный список хранит элементы в узлах, разбросанных по памяти, и связывает их указателями. Динамический массив хранит элементы в непрерывной области памяти. Список быстрее при вставке/удалении в середине (если есть указатель на узел), но медленнее при доступе по индексу.
</details>

<details>
<summary>2. Какие операции в односвязном списке выполняются за O(1)?</summary>
Вставка в начало (`push_front`), удаление из начала (`pop_front`), вставка в конец (`push_back`, если есть `tail`).
</details>

<details>
<summary>3. Почему удаление из конца односвязного списка требует O(n) времени?</summary>
Потому что, даже имея указатель на `tail`, мы не можем получить доступ к предпоследнему узлу за O(1), так как нет указателя `prev`. Приходится проходить весь список сначала, чтобы найти узел перед хвостом.
</details>

<details>
<summary>4. Какие преимущества даёт хранение указателя tail в односвязном списке?</summary>
Позволяет выполнять вставку в конец (`push_back`) за O(1), а не за O(n).
</details>

<details>
<summary>5. Чем двусвязный список отличается от односвязного?</summary>
Каждый узел двусвязного списка хранит указатель не только на следующий, но и на предыдущий элемент. Это позволяет обходить список в обоих направлениях и удалять элементы из конца за O(1).
</details>

<details>
<summary>6. Какие операции в двусвязном списке выполняются быстрее, чем в односвязном?</summary>
Удаление из конца (`pop_back`) — O(1) против O(n). Также вставка/удаление перед заданным узлом, если есть указатель на него.
</details>

<details>
<summary>7. Что такое «голова» (head) и «хвост» (tail) списка?</summary>
`Head` — указатель на первый узел списка. `Tail` — указатель на последний узел списка.
</details>

<details>
<summary>8. Как удалить узел из середины односвязного списка?</summary>
Нужно найти узел, предшествующий удаляемому, и изменить его указатель `next` так, чтобы он указывал на узел после удаляемого. Затем удалить целевой узел. Сложность O(n) из-за поиска.
</details>

<details>
<summary>9. Как удалить узел из середины двусвязного списка? Почему это проще?</summary>
Если есть указатель на удаляемый узел, можно сразу получить доступ к предыдущему и следующему узлам через `prev` и `next`, и переставить их указатели. Сложность O(1).
</details>

<details>
<summary>10. Что произойдёт, если забыть обновить tail при удалении?</summary>
Указатель `tail` будет указывать на удалённую память (висячий указатель). Последующие операции с хвостом приведут к неопределённому поведению или падению программы.
</details>

<details>
<summary>11. Как реализовать реверс односвязного списка?</summary>
Нужно пройти по списку, сохраняя указатели на предыдущий, текущий и следующий узлы, и разворачивать указатели `next` в обратную сторону.
</details>

<details>
<summary>12. Как обнаружить цикл в связном списке?</summary>
Использовать алгоритм «черепахи и зайца» (два указателя, один движется в два раза быстрее). Если они встретятся, значит, есть цикл.
</details>

<details>
<summary>13. В каких случаях стоит использовать список вместо массива?</summary>
Когда требуется частая вставка и удаление элементов в произвольных местах, и не требуется частый доступ по индексу.
</details>

<details>
<summary>14. Какая дополнительная память требуется для каждого узла списка?</summary>
Для односвязного — один указатель (`next`), для двусвязного — два (`prev`, `next`).
</details>

<details>
<summary>15. Почему доступ по индексу в списке имеет сложность O(n)?</summary>
Потому что элементы списка не хранятся непрерывно, и чтобы добраться до i-го элемента, нужно пройти все предыдущие узлы.
</details>
