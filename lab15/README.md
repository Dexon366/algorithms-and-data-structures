## Теоретическая часть
**Алгоритм КМП** — эффективный алгоритм поиска подстроки в строке. Использует **префикс-функцию** для определения, на сколько можно сдвинуть образец при несовпадении, не возвращаясь назад по тексту. Сложность \(O(n + m)\).

**STL (Standard Template Library)** — набор контейнеров (vector, list, map, set), итераторов и алгоритмов (sort, find, accumulate), которые упрощают разработку на C++.

## Описание реализованного алгоритма

### Префикс-функция
`pi[i]` — длина наибольшего собственного префикса строки `s[0..i]`, который также является суффиксом. Вычисляется за \(O(m)\) с использованием предыдущих значений.

### КМП
Идем по тексту, поддерживая `j` — количество совпавших символов образца. При несовпадении сдвигаем `j` по префикс-функции. При `j == m` фиксируем вхождение и продолжаем с `j = pi[j-1]` (для перекрытия).

### STL: Сортировка студентов
Используется `vector<Student>`, где `Student` содержит имя и балл. `sort` с кастомным компаратором сортирует по убыванию баллов, затем по имени.

## Описание основных функций и структур данных
*   **`computePrefixFunction`** — вычисление префикс-функции.
*   **`kmpSearch`** — поиск вхождений с перекрытием.
*   **`Student`** — структура для студента.
*   **`compareStudents`** — компаратор для сортировки.

## Анализ сложности
| Алгоритм | Время | Память |
| :--- | :--- | :--- |
| Префикс-функция | O(m) | O(m) |
| КМП | O(n + m) | O(m) |
| Сортировка (STL) | O(k log k) | O(1) |

## Ответы на контрольные вопросы
<details>
<summary>1. В чём заключается идея алгоритма Кнута-Морриса-Пратта?</summary>
Использовать префикс-функцию для эффективного сдвига образца при несовпадении, не возвращаясь назад по тексту.
</details>

<details>
<summary>2. Что такое префикс-функция и как она вычисляется?</summary>
Длина наибольшего собственного префикса строки, который также является суффиксом. Вычисляется за O(m) с использованием предыдущих значений.
</details>

<details>
<summary>3. Какова временная сложность алгоритма КМП? Почему?</summary>
O(n + m), где n — длина текста, m — длина образца. Потому что каждый символ текста обрабатывается один раз.
</details>

<details>
<summary>4. Как работает восстановление по префикс-функции при несовпадении?</summary>
Если символы не совпадают, сдвигаем j на pi[j-1], пока не найдем совпадение или j не станет 0.
</details>

<details>
<summary>5. В чём преимущество КМП перед наивным алгоритмом?</summary>
КМП работает за O(n + m), а наивный — за O(n * m). КМП не возвращается назад по тексту.
</details>

<details>
<summary>6. Какие контейнеры STL вы знаете? Какой контейнер когда лучше использовать?</summary>
vector (динамический массив), list (связный список), deque (двусторонняя очередь), set/map (сбалансированное дерево), unordered_set/unordered_map (хеш-таблица). Выбор зависит от задачи: vector для частого доступа по индексу, list для частых вставок/удалений.
</details>

<details>
<summary>7. В чём разница между vector и list?</summary>
vector хранит элементы непрерывно (быстрый доступ по индексу, медленные вставки/удаления в середине). list — связный список (быстрые вставки/удаления, медленный доступ по индексу).
</details>

<details>
<summary>8. В чём разница между set и unordered_set?</summary>
set — сбалансированное дерево (упорядоченные элементы, O(log n) операции). unordered_set — хеш-таблица (неупорядоченные, O(1) в среднем).
</details>

<details>
<summary>9. В чём разница между map и unordered_map?</summary>
map — упорядоченный словарь (O(log n)). unordered_map — хеш-таблица (O(1) в среднем).
</details>

<details>
<summary>10. Как работают итераторы в STL?</summary>
Итераторы — объекты, позволяющие перебирать элементы контейнера. Поддерживают операции *, ++, ==, !=. Бывают прямые, двунаправленные, произвольного доступа.
</details>

<details>
<summary>11. Какие алгоритмы STL вы знаете? Приведите примеры.</summary>
sort, find, count, accumulate, transform, reverse, remove, min_element, max_element.
</details>

<details>
<summary>12. Что такое лямбда-выражения в C++? Как они применяются с алгоритмами STL?</summary>
Анонимные функции. Используются для передачи кастомных операций в алгоритмы (например, компаратор для sort, предикат для count_if).
</details>

<details>
<summary>13. Как удалить элементы из контейнера во время итерации?</summary>
Использовать идиому erase-remove: `v.erase(remove(v.begin(), v.end(), value), v.end())`.
</details>

<details>
<summary>14. Что такое идиома erase-remove?</summary>
Способ удаления элементов из контейнера: `remove` перемещает ненужные элементы в конец, возвращая новый конец, а `erase` удаляет их.
</details>

<details>
<summary>15. Как можно изменить порядок обхода контейнера?</summary>
Использовать обратные итераторы (rbegin, rend) или изменить порядок сортировки.
</details>
