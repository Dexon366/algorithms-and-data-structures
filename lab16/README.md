## Теоретическая часть
**Наследование** — механизм создания нового класса на основе существующего. **Полиморфизм** — возможность вызова методов производного класса через указатель на базовый. **Абстрактный класс** — класс с чисто виртуальными методами, не может иметь экземпляров. **Виртуальный деструктор** необходим для корректного удаления объектов производных классов.

## Описание реализованного алгоритма

### Иерархия классов
Базовый абстрактный `Student` содержит чисто виртуальные методы `getType()`, `attendClass()`, `getInfo()` и виртуальный `calculateScholarship()`. Производные классы реализуют эти методы.

### Система курсов
Класс `Course` хранит название, преподавателя, список студентов и их оценки. Методы `enrollStudent`, `setGrade`, `printCourseInfo`.

### Расписание
Класс `Schedule` хранит записи (день, время, курс). Метод `printSchedule`.

### Сериализация
Сохранение в текстовый файл: количество студентов, для каждого — тип, имя, курс, группа. Затем количество курсов, для каждого — название, преподаватель, список студентов с оценками. Загрузка выполняется в обратном порядке.

## Ответы на контрольные вопросы
<details>
<summary>1. Что такое наследование? Какие виды наследования есть в С++?</summary>
Механизм создания нового класса на основе существующего. Виды: public, protected, private.
</details>

<details>
<summary>2. Что такое открытое (public) наследование? Какое отношение оно реализует?</summary>
Публичное наследование реализует отношение «is a» (является).
</details>

<details>
<summary>3. Что такое виртуальный метод? Для чего он нужен?</summary>
Метод, который может быть переопределён в производном классе, и вызов через указатель на базовый класс направляется к производному (позднее связывание).
</details>

<details>
<summary>4. Что такое чисто виртуальный метод и абстрактный класс?</summary>
Чисто виртуальный метод не имеет реализации (`= 0`). Класс с таким методом является абстрактным, нельзя создавать его экземпляры.
</details>

<details>
<summary>5. Почему деструктор базового класса должен быть виртуальным?</summary>
Чтобы при удалении объекта через указатель на базовый класс вызывался деструктор производного класса, предотвращая утечки памяти.
</details>

<details>
<summary>6. Что такое позднее связывание (динамический полиморфизм)?</summary>
Связывание вызова метода с его реализацией происходит во время выполнения, а не компиляции.
</details>

<details>
<summary>7. Как переопределить метод в производном классе? Что такое override?</summary>
Использовать ключевое слово `override` для явного указания переопределения.
</details>

<details>
<summary>8. Что такое RTTI? Как работает dynamic_cast?</summary>
RTTI — идентификация типов во время выполнения. `dynamic_cast` безопасно преобразует указатели между типами в иерархии.
</details>

<details>
<summary>9. Как вызвать метод базового класса из производного?</summary>
Использовать `Base::method()`.
</details>

<details>
<summary>10. Что такое диаграмма классов UML? Какие основные элементы?</summary>
Диаграмма для визуализации классов и их отношений. Элементы: классы, атрибуты, методы, наследование, ассоциации.
</details>

<details>
<summary>11. Что такое паттерн «Стратегия»? Где он применяется?</summary>
Паттерн, инкапсулирующий семейство алгоритмов. Применяется, когда нужно динамически менять алгоритм.
</details>

<details>
<summary>12. Что такое виртуальный деструктор? Почему он важен?</summary>
Деструктор, помеченный `virtual`. Важен для корректного удаления объектов производных классов через указатель на базовый.
</details>
